
# Incidentes de ciberseguridad: prácticas con PowerShell y Bash

## 1. Objetivo de la clase

El objetivo de esta unidad es aprender a utilizar PowerShell (Windows) y Bash (Linux) como herramientas para realizar auditorías de seguridad, detectar incidentes, recopilar evidencias, investigar actividades sospechosas y aplicar medidas de respuesta y contención.

En lugar de estudiar ambos intérpretes de comandos de forma aislada, se utilizarán para simular el trabajo de un analista de ciberseguridad que debe identificar, investigar, documentar y responder ante un incidente.

### Escenario de trabajo

Un empleado comunica que su ordenador presenta un comportamiento extraño. El equipo de seguridad sospecha que:

- Se han producido múltiples intentos de acceso fallidos.
- Existe un proceso desconocido ejecutándose.
- Se han establecido conexiones de red sospechosas.
- Puede haberse instalado un servicio no autorizado.
- Es necesario recopilar evidencias antes de intervenir.

**Misión:** actuar como analistas de un equipo SOC (Security Operations Center), detectar el incidente, obtener evidencias, analizar los indicadores, valorar el riesgo, documentar lo ocurrido y proponer medidas de contención.

# 2. Auditoría del sistema y prevención

## 2.1. Objetivos

Relacionar los comandos con los siguientes contenidos:

- Principios generales de ciberseguridad.
- Normativa de protección del puesto de trabajo.
- Auditorías internas de cumplimiento.
- Identificación de debilidades.
- Identificación de configuraciones inseguras.
- Control de usuarios y permisos.

## 2.2. PowerShell: auditoría de Windows

### Obtener información del sistema

```powershell
Get-ComputerInfo | Select-Object WindowsProductName, WindowsVersion, OsBuildNumber
```

### Consultar usuarios locales

```powershell
Get-LocalUser
```

### Consultar usuarios administradores

```powershell
Get-LocalGroupMember -Group "Administrators"
```

### Consultar servicios en ejecución

```powershell
Get-Service | Where-Object Status -eq "Running"
```

### Consultar el estado del firewall

```powershell
Get-NetFirewallProfile
```

### Consultar el estado de Microsoft Defender

```powershell
Get-MpComputerStatus |
Select-Object AntivirusEnabled, RealTimeProtectionEnabled, AntivirusSignatureLastUpdated
```

## 2.3. Bash: auditoría de Linux

### Obtener información del sistema

```bash
uname -a
```

### Consultar usuarios conectados

```bash
who
```

### Consultar usuarios existentes

```bash
cat /etc/passwd
```

### Consultar usuarios del grupo sudo

```bash
getent group sudo
```

### Consultar servicios activos

```bash
systemctl --type=service --state=running
```

### Consultar el estado del firewall

```bash
sudo ufw status verbose
```

### Consultar actualizaciones pendientes en Debian/Ubuntu

```bash
apt list --upgradable
```

### Conceptos que se deben explicar

- Principio de mínimo privilegio.
- Gestión de usuarios y permisos.
- Servicios innecesarios.

# 3. Detección de incidentes y monitorización

## 3.1. Objetivos

- Consultar registros de seguridad.
- Identificar intentos de acceso fallidos.
- Detectar accesos no autorizados.
- Identificar anomalías.
- Analizar eventos del sistema.
- Comprender la trazabilidad de las operaciones.

## 3.2. PowerShell: análisis de eventos de Windows

### Consultar los últimos eventos de seguridad

```powershell
Get-WinEvent -LogName Security -MaxEvents 20
```

### Buscar intentos fallidos de inicio de sesión (evento 4625)

```powershell
Get-WinEvent -FilterHashtable @{
    LogName = 'Security'
    Id = 4625
    StartTime = (Get-Date).AddDays(-1)
}
```

### Buscar inicios de sesión correctos (evento 4624)

```powershell
Get-WinEvent -FilterHashtable @{
    LogName = 'Security'
    Id = 4624
    StartTime = (Get-Date).AddDays(-1)
}
```

### Buscar instalaciones de nuevos servicios (evento 7045)

```powershell
Get-WinEvent -FilterHashtable @{
    LogName = 'System'
    Id = 7045
}
```

### Consultar eventos de PowerShell

```powershell
Get-WinEvent -LogName "Microsoft-Windows-PowerShell/Operational" -MaxEvents 30
```

### Conceptos que se deben explicar

- Event Viewer.
- Registros de seguridad.
- Eventos de autenticación.
- Intentos de fuerza bruta.
- Identificación de accesos anómalos.
- Correlación de eventos.
- Monitorización continua.

## 3.3. Bash: análisis de registros de Linux

### Consultar los últimos accesos

```bash
last
```

### Consultar intentos fallidos de autenticación SSH

```bash
sudo journalctl -u ssh --since "24 hours ago"
```

### Buscar contraseñas incorrectas en Debian/Ubuntu

```bash
sudo grep -i "failed password" /var/log/auth.log
```

### Buscar accesos correctos mediante SSH

```bash
sudo grep -i "accepted" /var/log/auth.log
```

### Consultar los últimos mensajes del sistema

```bash
sudo journalctl -n 100
```

### Consultar los eventos de las últimas 24 horas

```bash
sudo journalctl --since "24 hours ago"
```

### Conceptos que se deben explicar

- Logs del sistema.
- Autenticación SSH.
- Intentos de acceso fallidos.
- Identificación de patrones sospechosos.
- Trazabilidad.
- Monitorización de servicios.

**Nota:** dependiendo de la distribución Linux, los registros de autenticación pueden encontrarse en `/var/log/auth.log` o `/var/log/secure`. También puede utilizarse `journalctl`.

# 4. Monitorización de procesos y conexiones de red

## 4.1. Objetivos

- Consultar puertos abiertos.
- Identificar servicios en escucha.
- Relacionar procesos con conexiones de red.
- Detectar posibles comunicaciones no autorizadas.

## 4.2. PowerShell: procesos y conexiones de Windows

### Consultar procesos activos

```powershell
Get-Process
```

### Ordenar procesos por consumo de CPU

```powershell
Get-Process | Sort-Object CPU -Descending
```

### Consultar los diez procesos que más memoria consumen

```powershell
Get-Process |
Sort-Object WorkingSet64 -Descending |
Select-Object -First 10 Name, Id, WorkingSet64
```

### Consultar conexiones TCP

```powershell
Get-NetTCPConnection
```

### Consultar conexiones establecidas

```powershell
Get-NetTCPConnection -State Established
```

### Consultar conexiones y procesos asociados

```powershell
Get-NetTCPConnection -State Established |
Select-Object LocalAddress, LocalPort, RemoteAddress, RemotePort, OwningProcess
```

### Identificar un proceso por su PID

```powershell
Get-Process -Id 1234
```

### Consultar puertos en escucha

```powershell
Get-NetTCPConnection -State Listen
```

# 5. Recopilación y análisis de evidencias

## 5.1. Objetivos

- Recopilar información relevante.
- Preservar la integridad de las evidencias.
- Calcular funciones hash.
- Documentar los archivos recopilados.
- Comprender la cadena de custodia.
- Evitar modificaciones de las evidencias originales.

## 5.2. PowerShell: cálculo de hashes

### Calcular SHA-256 de un archivo

```powershell
Get-FileHash .\archivo.exe -Algorithm SHA256
```

### Calcular hashes de todos los archivos de una carpeta

```powershell
Get-ChildItem C:\Evidencias -File -Recurse |
Get-FileHash -Algorithm SHA256
```

### Exportar hashes a CSV

```powershell
Get-ChildItem C:\Evidencias -File -Recurse |
Get-FileHash -Algorithm SHA256 |
Export-Csv C:\Evidencias\hashes.csv -NoTypeInformation
```

## 5.3. Bash: cálculo de hashes

### Calcular SHA-256

```bash
sha256sum archivo.exe
```

### Calcular hashes de todos los archivos de una carpeta

```bash
find ./evidencias -type f -exec sha256sum {} \;
```

### Guardar hashes en un archivo

```bash
find ./evidencias -type f -exec sha256sum {} \; > hashes.txt
```

### Comprobar posteriormente la integridad

```bash
sha256sum -c hashes.txt
```

## 5.4. Demostración práctica: detectar modificaciones

1. Crear un archivo de texto.
2. Calcular su hash SHA-256.
3. Modificar una palabra del documento.
4. Volver a calcular su hash.
5. Comparar ambos resultados.

El alumnado comprobará que un cambio mínimo en el contenido genera un hash diferente.

### Conceptos que se deben explicar

- Funciones hash.
- SHA-256.
- MD5 y sus limitaciones.
- Integridad de las evidencias.
- Cadena de custodia.
- Recopilación forense.
- Documentación de evidencias.
- Preservación de archivos originales.

**Importante:** estos comandos permiten realizar una recopilación básica. Una investigación forense formal requiere procedimientos adicionales para preservar los originales, registrar fechas, zona horaria, responsables y métodos de adquisición.

# 6. Criptografía, certificados y comunicaciones seguras

## 6.1. Objetivos

- Comprender la criptografía simétrica y asimétrica.
- Generar claves públicas y privadas.
- Calcular funciones hash.
- Crear y verificar firmas digitales.
- Consultar certificados digitales.
- Comprender la infraestructura PKI.
- Identificar el funcionamiento de TLS.

## 6.2. PowerShell: consulta de certificados

### Consultar certificados del usuario

```powershell
Get-ChildItem Cert:\CurrentUser\My
```

### Consultar certificados del equipo

```powershell
Get-ChildItem Cert:\LocalMachine\My
```

### Consultar conectividad HTTPS

```powershell
Test-NetConnection google.com -Port 443
```

## 6.3. Bash: criptografía con OpenSSL

### Generar un hash SHA-256

```bash
echo -n "Ciberseguridad" | sha256sum
```

### Generar un par de claves RSA

```bash
openssl genrsa -out privada.pem 2048
```

### Extraer la clave pública

```bash
openssl rsa -in privada.pem -pubout -out publica.pem
```

### Crear una firma digital

```bash
openssl dgst -sha256 -sign privada.pem \
-out firma.bin documento.txt
```

### Verificar la firma digital

```bash
openssl dgst -sha256 -verify publica.pem \
-signature firma.bin documento.txt
```

### Consultar el certificado TLS de una web

```bash
openssl s_client -connect google.com:443 \
-servername google.com </dev/null
```

### Conceptos que se deben explicar

- Criptografía simétrica.
- Criptografía asimétrica.
- Claves públicas y privadas.
- Funciones hash.
- Firma digital.
- Certificados X.509.
- Infraestructura de clave pública (PKI).
- Autoridades de certificación.
- Protocolo TLS.
- Intercambio de claves Diffie-Hellman.

# 8. Contención y respuesta ante incidentes

## 8.1. Objetivos

- Aplicar medidas de contención.
- Bloquear comunicaciones sospechosas.
- Detener procesos.
- Deshabilitar cuentas comprometidas.
- Detener servicios afectados.
- Reducir el impacto de un incidente.

## 8.2. PowerShell: medidas de contención en Windows

### Consultar reglas del firewall

```powershell
Get-NetFirewallRule
```

### Bloquear una dirección IP

```powershell
New-NetFirewallRule `
-DisplayName "Bloqueo IP sospechosa" `
-Direction Outbound `
-RemoteAddress 203.0.113.50 `
-Action Block
```

### Deshabilitar una cuenta local

```powershell
Disable-LocalUser -Name "usuario"
```

### Detener un proceso

```powershell
Stop-Process -Id 1234
```

## 8.3. Bash: medidas de contención en Linux

### Bloquear una dirección IP mediante UFW

```bash
sudo ufw deny from 203.0.113.50
```

### Consultar reglas del firewall

```bash
sudo ufw status numbered
```

### Detener un servicio

```bash
sudo systemctl stop nombre-servicio
```

### Deshabilitar un servicio

```bash
sudo systemctl disable nombre-servicio
```

### Finalizar un proceso

```bash
sudo kill -TERM 1234
```

**Importante:** la IP `203.0.113.50` pertenece a un rango reservado para documentación y pruebas.

**Advertencia operativa:** no siempre se debe detener inmediatamente un proceso o apagar un equipo. Antes de intervenir hay que valorar la preservación de evidencias, el impacto sobre los servicios y las medidas de contención adecuadas.

# 9. Documentación y seguimiento del incidente

## 9.1. Objetivos

- Registrar las actuaciones realizadas.
- Generar informes automáticos.
- Documentar procesos, servicios y conexiones.
- Conservar los registros.
- Facilitar la investigación posterior.
- Establecer medidas correctoras.

## 9.2. PowerShell: generar un informe de recopilación

```powershell
$Fecha = Get-Date -Format "yyyyMMdd_HHmmss"
$Ruta = ".\incidente_$Fecha"

New-Item -ItemType Directory -Path $Ruta

# Información del sistema
Get-ComputerInfo |
Out-File "$Ruta\sistema.txt"

# Procesos activos
Get-Process |
Out-File "$Ruta\procesos.txt"

# Conexiones de red
Get-NetTCPConnection |
Export-Csv "$Ruta\conexiones.csv" -NoTypeInformation

# Servicios
Get-Service |
Export-Csv "$Ruta\servicios.csv" -NoTypeInformation

# Eventos de seguridad
Get-WinEvent -LogName Security -MaxEvents 100 |
Export-Csv "$Ruta\eventos_seguridad.csv" -NoTypeInformation

Write-Host "Recopilación finalizada: $Ruta"
```

## 9.3. Bash: generar un informe de recopilación

```bash
#!/bin/bash

FECHA=$(date +%Y%m%d_%H%M%S)
RUTA="./incidente_$FECHA"

mkdir -p "$RUTA"

# Información del sistema
uname -a > "$RUTA/sistema.txt"

# Usuarios conectados
who > "$RUTA/usuarios.txt"

# Procesos activos
ps aux > "$RUTA/procesos.txt"

# Conexiones de red
ss -tunap > "$RUTA/conexiones.txt" 2>&1

# Servicios activos
systemctl --type=service --state=running \
> "$RUTA/servicios.txt"

# Eventos recientes
sudo journalctl -n 200 \
> "$RUTA/eventos.txt"

echo "Recopilación finalizada: $RUTA"
```

Estos scripts realizan una adquisición inicial de información. Para utilizarlos en un procedimiento forense real hay que ampliar los datos recopilados y garantizar la integridad y trazabilidad de las evidencias.

# 10. Práctica completa: investigación de un incidente de seguridad

## 10.1. Descripción

Se plantea una investigación simulada en la que un servidor Linux recibe múltiples intentos de acceso mediante SSH y un equipo Windows presenta conexiones de red que deben analizarse.

Los alumnos actuarán como analistas SOC y deberán realizar las tareas necesarias para identificar el origen del problema, recopilar evidencias y documentar las actuaciones.

## 10.2. Fases de la investigación

### Fase 1. Identificación

Consultar los registros de acceso e identificar los intentos fallidos.

Linux:

```bash
sudo journalctl -u ssh --since "24 hours ago"
```

Windows:

```powershell
Get-WinEvent -FilterHashtable @{
    LogName = 'Security'
    Id = 4625
    StartTime = (Get-Date).AddDays(-1)
}
```

### Fase 2. Monitorización

Analizar procesos, servicios, conexiones y puertos abiertos.

Linux:

```bash
ps aux
ss -tunap
ss -tulnp
```

Windows:

```powershell
Get-Process
Get-NetTCPConnection
Get-Service
```

### Fase 3. Recopilación de evidencias

Recopilar registros, información del sistema y hashes SHA-256.

Linux:

```bash
sudo journalctl -n 200 > eventos.txt
sha256sum eventos.txt
```

Windows:

```powershell
Get-WinEvent -LogName Security -MaxEvents 100 |
Export-Csv eventos.csv -NoTypeInformation

Get-FileHash eventos.csv -Algorithm SHA256
```

### Fase 4. Investigación

Analizar las direcciones IP, dominios, puertos, procesos y actividad sospechosa.

Herramientas:

- dig.
- whois.
- Resolve-DnsName.
- VirusTotal.
- AbuseIPDB.
- Shodan.

### Fase 5. Contención

Proponer medidas de respuesta:

- Bloquear una dirección IP.
- Deshabilitar una cuenta comprometida.
- Detener un proceso sospechoso.
- Detener un servicio afectado.
- Revisar las reglas del firewall.

### Fase 6. Documentación

Elaborar un informe con:

- Identificación del incidente.
- Fecha y hora.
- Sistemas afectados.
- Descripción de lo ocurrido.
- Evidencias recopiladas.
- Indicadores de compromiso.
- Impacto estimado.
- Medidas de contención.
- Recomendaciones.
- Seguimiento.

# 15. Conclusión

PowerShell y Bash son herramientas fundamentales para la administración y la seguridad de sistemas. Su utilización permite realizar auditorías, consultar registros, monitorizar procesos, analizar conexiones, recopilar evidencias y aplicar medidas de respuesta ante incidentes.

La finalidad de estas prácticas es que el alumnado comprenda el ciclo completo de gestión de un incidente:

1. Prevención.
2. Monitorización.
3. Detección.
4. Identificación.
5. Investigación.
6. Recopilación de evidencias.
7. Contención.
8. Recuperación.
9. Documentación.
10. Seguimiento y mejora continua.

La combinación de PowerShell, Bash y herramientas como Wazuh, Wireshark y Velociraptor permite desarrollar un laboratorio práctico que reproduce situaciones habituales en los equipos de seguridad informática.
